## Bloqueador atual

### G1-01 - Repositorio sem commit inicial

O repositorio ainda nao possui `HEAD` e todos os arquivos aparecem como nao rastreados. Sem um commit inicial, nao e possivel associar o codigo, as evidencias e a imagem candidata a uma versao imutavel nem executar rollback confiavel.

**Prioridade:** P0 para publicacao.

**Acao necessaria:** revisar os arquivos que devem pertencer ao repositorio, criar o commit inicial e registrar seu identificador neste documento.
