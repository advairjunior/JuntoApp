# Juntô

Diário compartilhado de encontros para grupos de amigos.

## Executar localmente

Com o Docker Desktop aberto e o arquivo `.env` configurado, execute na raiz:

```powershell
.\rodar.ps1
```

O aplicativo ficará disponível em `http://localhost:5391`.

Não existe conta padrão. No primeiro acesso, crie a conta informando nome,
celular brasileiro e um PIN de seis dígitos.
