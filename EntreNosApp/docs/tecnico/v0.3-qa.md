## Correcoes feitas durante QA

### Swagger nao carregava

Problema:

- o Swagger retornava erro interno ao gerar `swagger.json`.
- a rota de memoria usava `[FromForm] IFormFile arquivo`, formato que causou falha na geracao do contrato.

Correcao:

- a assinatura foi ajustada para `IFormFile arquivo`, seguindo o padrao da rota de imagem de capa.
- o `swagger.json` voltou a responder `200 OK`.

### Usuario nao conseguia subir foto

Problema:

- o backend exigia encontro `Realizado` para criar memoria.
- o app ainda nao possuia uma acao clara para marcar o encontro como realizado.

Correcao:

- foi adicionada a acao `Marcar como realizado` na tela de informacoes do encontro.
- a acao aparece apenas para usuario autorizado.
- depois da revisao de produto, a tela de midias nao depende mais do estado `Realizado` para adicionar fotos.

### Falta de massa local para teste

Problema:

- sem massa local, o usuario precisava preparar manualmente todo o fluxo antes de testar memorias.

Correcao:

- foi criado o encontro local `Noite de Memórias`.
- todos os usuarios ativos locais foram vinculados como participantes confirmados.

## Riscos residuais

- Arquivos ainda sao servidos por `wwwroot`, adequado para desenvolvimento, mas insuficiente para privacidade definitiva em producao.
- Upload foi validado por testes automatizados e estrutura mobile, mas ainda precisa de teste manual no app com imagem real.
- iPhone fisico ainda nao foi validado.
- Videos continuam fora da entrega P0 da v0.3.
- O app ainda depende da API local e do PostgreSQL local durante desenvolvimento.
